# Translational philosophy

Apply `doc/TRANSLATIONAL_PHILOSOPHY.md` whenever adding or changing researcher-facing
scientific content, a model, metric, method, explanation, figure, inspector, narrative or export.

Start from an unfamiliar researcher's question. Explain the supported meaning, reference frame,
provenance and limitations. Preserve missingness and the recorded engine result. Contextual
explanation drawers teach their specific subject; they are not a universal help browser.

Add or update the topic's contextual entry point, content, sources and coverage checks together.
Use shared evidence models and thresholds; never create a second classification in help text.
Record coverage and verification in `doc/TRANSLATIONAL_COVERAGE.md`.
